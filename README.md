# RVNEX

**A Windows desktop application for managing and analyzing RVTools reports.**

RVNEX is an early-stage project. The v1.0.0 release artifacts are currently unsigned and runtime validation is still in progress.

## Status

- Project: early-stage / experimental
- Target: Windows x64
- Version: 1.0.0
- Signing: unsigned; Windows may block installation until a trusted signing path is configured
- Validation: complete end-to-end UI and live vCenter/ESXi export testing is pending

## Download

Check the [Releases](https://github.com/Amirkhatam/RVNEX/releases) page for downloadable builds. A release will be published there once a distributable package is available and installation notes are verified.

## Important

Do not install packages from untrusted sources. Never share vCenter/ESXi credentials in logs or issue reports.
